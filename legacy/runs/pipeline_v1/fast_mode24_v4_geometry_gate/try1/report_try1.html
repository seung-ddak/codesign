전체 실행 조건

  1. GitHub 최신 코드 d10ca76cb를 fast-forward 반영.
  2. CPU geometry·원본/보정 결과 구분 테스트 14개 실행.
  3. 문서 실행기로 2초 Zigzag 후보 4개씩 scale 0·1 생성. 동일 checkpoint·seed 0 사용.
  4. 생성 E에 맞춰 MuJoCo 지면 관통을 측정하고, 필요량+1mm의 높이 이동이 4cm 이내일 때만 적용. 이후 접촉과 geometry 재검사.
  5. CPU·MJX 무접촉 및 발 clearance 최소 5mm인 상태는 공중 시작으로 허용.
  6. 통과 후보에 한해 실제 MJX Open-loop stepping. 실패 결과 저장 후 exit code 1로 종료. 10초 실행 없음.

원본 TT pred와 predicted reward는 변경하지 않았습니다. 생성 상태와 실행 상태 보정은 summary의 preprojection·geometry_projection·executed_body_height_m에 별도로 기록됩니다.

실제 궤적과 TT 예측

해석과 한계

  • 기존의 무조건적인 2발 접촉 조건 때문에 제외되던 후보 하나가 이번 공중 시작 규칙으로 실제 실행에 진입했습니다.
  • 정적 geometry를 통과한 원본 생성 상태에서도 두 rollout 모두 낙상했습니다. 초기 지면 관통만 해결하면 2초 동작이 성공한다는 가설은 이 후보에서 지지되지 않습니다.
  • Guided 유효 구간 reward는 -2.2987, baseline은 -2.7454지만 유효 시간이 0.50초와 1.68초로 다릅니다. 이를 guidance 성능 개선으로 해석하면 안 됩니다. 현재 reward는 일부 항목의 구간 평균과 진행량을 합칩니다.
  • 이전 실험과 같은 seed·checkpoint의 재사용이며 독립적인 성공률 추정이 아닙니다. Gate 미통과 후 임의로 후보 수·높이 상한을 늘리지 않았습니다.
  • 다음 판단에는 생성 행동과 실제 상태 변화의 불일치, 초기 속도/자세 및 학습·sampling 품질을 분리한 진단이 필요합니다. 이번에는 요청된 실행기 범위에서 중단했습니다.

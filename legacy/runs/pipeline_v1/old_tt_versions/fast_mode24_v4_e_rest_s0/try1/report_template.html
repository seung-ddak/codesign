TT 생성 형상의 MJX 실제 동작 확인

TT joint diffusion 이 만든 형상(E)·초기상태(S0)·동작(A)을 MuJoCo(MJX)에서 그대로 재생했다. 결론: 8개 후보 중 MJX 2초 완주는 3개이고 MJX R 은 모두 음수다. TT 예측과 실제 결과의 차이가 커서 guidance 가 실제 성능 개선으로 이어지지 않는다.

질문과 답

현재 문제가 뭐야?

gate 9/9 PASS 는 계산 그래프가 연결돼 있고 코드가 끝까지 돈다는 것만 보여 준다. TT 예측 R 과 MJX 실제 R 이 크게 다르고, E gradient 검사는 "connectivity only" 다. 그래서 guidance 가 MJX 실제 결과가 아니라 틀린 TT 예측을 최적화한다.

그러면 결론은 지금 TT가 guidence를 이용해서 S,E,A 예측을 하지만 그 결과를 물리시뮬레이션에서 작동 시켰을 때는 정상적으로 작동이 되지 않는다는거야?

대체로 맞다. 두 가지를 덧붙인다.

  1. 일부 후보는 2초 동안 넘어지지 않는다. 하지만 R 이 모두 음수라 zigzag 과제는 수행하지 못한다.
  2. guidance 를 끈 baseline 도 MJX 에서 똑같이 잘 안 된다. 근본 원인은 TT 가 생성한 S·E·A 자체가 물리적으로 맞지 않는 것이고, 형상이 바뀔 때의 동역학 차이를 TT 가 잘 예측하지 못하는 것이다.

그러면 TT에서 예측한 형상을 사진으로 찍어봐 그리고 MJX에서 작동하는 영상을 찍어서 report 보고서로 만들어봐

아래 후보별 카드에 정리했다. 왼쪽 사진은 MJX 시작 순간(S0)의 형상이고, 오른쪽은 2초 MJX 영상이다. 영상에서 흰 점은 lane 경계, 파란 점은 TT 가 예측한 몸통 경로다. 파란 점에서 벗어난 만큼이 예측과 실제의 차이다.

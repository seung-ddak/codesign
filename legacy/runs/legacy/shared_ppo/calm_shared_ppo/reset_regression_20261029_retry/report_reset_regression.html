조건부 MJX reset 회귀 테스트

2026년 10월 29일 · 32 parallel environments · 30Hz control / 300Hz physics

조건부 reset 실행 통과 · PPO callback 로깅은 별도 실패
결론: 로깅을 끈 재실행에서 조건부 reset 경로는 GPU 실행을 통과했다.

32개 환경에서 4-step episode 종료·reset을 반복했고, 128 전이 PPO 업데이트와 평가, step 128 체크포인트 저장이 완료됐다. 32개 rollout 모두 길이 4, 상태 배열 유효, 단일 활성 형상 near_short로 기록됐다.

범위 제한: 이번 실행은 reset·학습 wiring의 회귀 테스트다. 에피소드는 4 control step, 약 0.133초다. 10초 tracking, 정책 수렴, 연구 성능은 검증하지 않았다. 기록기의 completed는 이 테스트에서 설정한 짧은 episode horizon에 도달했다는 분류이며, 10초 생존을 뜻하지 않는다.

평가 평균과 fallover 비율은 성공한 재실행의 콘솔 출력에서 기록했다. 짧은 테스트 결과이므로 단계 승급 판단에 사용하지 않는다.

실제 rollout 데이터 시각화

이 테스트는 렌더링을 끄고 4-step으로 실행했으므로 실제 3D 로봇 영상은 생성하지 않았다. 기존 try4 영상은 다른 정책/실험 결과라 이번 회귀 테스트 영상처럼 붙이지 않았다.

첫 실행 실패와 재실행

실행설정/관측판정
첫 실행log_training_metrics=true; episode 종료 뒤 JAX callback에서 EpisodeMetricsLogger.update_episode_metrics()가 필수 인자 train_metrics 없이 호출됨실패
재실행log_training_metrics=false; 나머지 reset 강제 조건은 동일128 전이 학습·평가·저장 성공

해석: 관측된 첫 실패는 선택형 training metrics callback의 호출 서명 불일치다. logger를 끄면 reset 경로가 작동한다는 점은 검증됐다. 따라서 기본 설정의 metrics logging 경로가 해결됐다고 말할 수 없으며, 로그 사용을 유지하려면 callback 호출부/인터페이스를 수정한 뒤 별도 재검증해야 한다.

# Jump 리타겟팅 검증 — PPO 제외

## 판정

**현재 결과는 상승·하강 궤적 보존 조건을 통과하지 못한다.** TT 네 형상 모두 A1보다 몸체 높이 정점이 120 ms 빠르다. 이는 실제 동역학 낙하나 착지 시점 측정이 아니라, 저장된 레퍼런스 자체의 조기 하강이다.

## 입력과 비교 기준

- A1: `artifacts/pd_replay/jumpInPlace.npz`의 `fix_base_pos`. TT에 저장된 `a1_qpos`와 일치함을 검사했다.
- TT: `artifacts/retarget_tt/{00000000,00000001,00000010,00000011}/jumpInPlace.npz`의 `fix_*`.
- 모두 98프레임, 20 ms 간격. PPO 체크포인트, 정책, 물리 적분은 사용하지 않았다.
- A1의 첫 무접촉 프레임인 클립 0.66 s를 공통 이벤트로 사용했다. 각 로봇에 대해 `h(t) = z(t) - z(0.66)`로 정규화하고, 시간축도 공통으로 `t - 0.66`을 사용했다. 진폭 배율 조정이나 개별 시간 정렬은 하지 않았다.
- 이는 **A1 이륙 라벨 기준**이다. 접촉 라벨이 단속적이고 TT는 라벨 정리를 거치므로 물리적 이륙을 확정한 것은 아니다. TT 자체 첫 무접촉 라벨은 0.86 s로, 이미 정점을 지난 뒤다. 이를 개별 기준으로 삼으면 비교 의미가 달라진다.

## 원인 위치와 조건별 해석

1. **궤적 보존: 미통과.** `pd_replay.retarget_tt`의 접촉 기반 높이 재계산, 공중 구간 오프셋 보간, 평활화를 그대로 복원했을 때 이미 정점이 0.64 s다. 따라서 조기 정점은 PPO나 최종 IK에서 처음 생긴 문제가 아니다. 이 세 연산 중 각각의 기여는 아직 분리하지 않았다. 다리 길이 배율 0.9375만으로는 정점 시각 이동을 설명할 수 없다.
2. **발 목표 추종: 잔차는 작으나 목표 적절성은 미통과.** 저장된 IK 목표와의 오차는 최대 1.11 mm 이하이다. 이것은 원본 A1 발 궤적과의 직접 오차가 아니다. TT 발 목표 자체가 최저 -15.31 mm로 바닥 아래를 요구하고, 결과도 약 14.6~14.8 mm 아래다. 발 중심에서 모델의 구 반지름 20 mm를 뺀 평지 기준 좌표다.
3. **몸체 높이와 발 목표의 양립: 추가 수정 필요.** IK는 발 목표를 잘 맞추지만 몸체 z는 입력 목표에서 최대 37~47 mm 벗어난다. 현재 몸체 위치 비용은 0.1, 발 위치 비용은 1.0이다. 잔차는 몸체 목표가 엄격히 유지되지 않음을 보여주지만, 목표 조합이 수학적으로 불가능하다는 증명은 아니다.
4. **관절 한계: 검사한 저장 프레임에서는 통과.** 모든 관절이 한계 내이며 최소 여유가 6.89 deg 이상이다. 재계산한 FK와 저장된 발 좌표도 1e-6 m 이내에서 일치했다.

사용자 지정 수치 허용오차가 없으므로 임의의 종합 점수를 만들지 않았다. 조기 정점과 지면 아래 발 목표라는 명확한 문제를 근거로 전체 통과를 보류한다.

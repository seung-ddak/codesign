# PPO 모션 트래킹 try1 (2026-11-10, 사용자 결정)
목적: TT 형상이 A1 CALM 모션을 PD 보다 잘 따라가는지 1 시간 학습으로 빠르게 확인.
- 형상 16 (e0000 + CALM 파일럿과 같은 15), 모션 학습 2,000 (형상당 125, 형상별 리타겟) + 평가 192 (학습 제외).
- 환경 30 Hz 제어 / 240 Hz 물리 (shared_calm 환경). PPO = v7 experts_wide16 값: num_envs 32, batch 32, unroll 24, minibatch 4, update 8, lr 1e-3, entropy 0.01, 256-128-64.
- 학습 최대 1 시간 (15M step 상한). 평가: 평가 모션 192, 외란·잡음 끔, 10 초 생존 · 추종 오차 · 1 초 방향 코사인 vs PD (0.46, 낙상 64 %).
- 판정 (사전 고정): 생존·방향 코사인 둘 다 PD 보다 높으면 유효 → 학습량 확대.

## 이어서 (사용자 결정: task 수행까지 한 번 끝까지)
1. PPO 정책으로 학습 모션 2,000 × 시작 조건 2 수집 (`shared_calm_collect.py`, 30 Hz).
2. TT 학습: h64_delta_track 과 같은 설정 (H64, delta, 60k step), 데이터만 PPO 수집 데이터.
3. task: task_v1 과 같은 명령, 단 재생 주기 30 Hz / 240 Hz (`TT_CONTROL_HZ`, `TT_PHYSICS_HZ`, 데이터 주기와 일치). 10 s = 300 step.

## task 보상 변경 (2026-11-10 12:3x, 사용자 요청, task 단계 전에 적용)
- TT 유도와 실제 채점이 같은 점수식 하나를 쓴다. 실제 채점 전용 항목 (조기 종료 −20, 게이트 보너스, 다음 게이트 거리, 폴 접촉 −20/회, 완주 시간) 제거.
- 추가 (양쪽 공통): 생존 감점 = 20 × 10 초 중 넘어진 뒤 비율 (넘어짐 기준 = 실제 채점과 같음, sigmoid), 슬라럼 폴 근접 감점 = 20 × 폴별 최대 근접도 합.
- 직진 = 최대 속도: 진행 표시 = 10 초 평균 전진 속도 (m/s).
- 따라서 이 run 의 task 점수는 이전 task_v1 (h64_delta_track 등) 점수와 직접 비교하지 않는다. 생존·진행·성공은 비교 가능.

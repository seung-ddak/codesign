TT는 넘어지지 않는 동작을 재현하는가

학습 데이터에서 로봇이 10초 동안 넘어지지 않은 에피소드를 골라, 같은 형상과 같은 시작 자세를 TT에 주고 행동을 생성하게 했다. 그 행동을 MuJoCo에서 실행해 로봇이 서 있는지 확인했다.

90 / 100
데이터의 실제 행동으로 실행 → 10초 생존
4 / 100
TT가 생성한 행동으로 실행 → 10초 생존 (중앙값 2.6초에 넘어짐)

결론: TT는 넘어지지 않는 동작을 재현하지 못한다.

  • 같은 형상과 시작 자세에서 실제 행동은 대부분 10초를 버티지만, TT가 만든 행동은 거의 모두 수 초 안에 넘어진다.
  • 실제 행동을 그대로 줘도 TT는 몸통이 어디로 가는지를 맞히지 못한다. "로봇이 제자리에 있다"고 가정한 것보다 오차가 크다.
  • 따라서 앞선 task 평가에서 모두 넘어진 원인은 reward gradient나 RL이 아니다. TT 자체에 있다. guidance나 RL 규모를 키우기 전에 TT를 고쳐야 한다.

무엇을 확인했나

  • 재료: 10k 데이터 중 TT 학습에 쓰지 않은 검증 에피소드에서, 넘어지지 않은 것 100개와 넘어진 것 100개를 무작위로 골랐다.
  • 확인 1 · 생성 후 실행: 형상 E와 시작 자세 s0만 TT에 주고, 10초 동안의 상태와 행동을 생성하게 했다. 생성된 행동을 MuJoCo에서 보정 없이 실행했다.
  • 확인 2 · 동역학 예측: 형상, 시작 자세, 실제 행동까지 모두 주고 TT가 10초 움직임을 예측하게 했다. 예측을 실제 기록과 비교했다.
  • 대조: 데이터의 실제 행동을 같은 MuJoCo 재생기로 실행했다. 재생기가 수집 때와 같은 결과를 내는지 확인하는 용도다.

  • 넘어지지 않은 에피소드에서 시작해도, TT의 결과는 넘어진 에피소드에서 시작했을 때와 크게 다르지 않다. TT가 "넘어지지 않는 행동"을 따로 구분해 내지 못한다는 뜻이다.
  • 실제 행동으로도 버티지 못한 10개 중 7개는 원래 데이터에서 10초보다 일찍 끝난 에피소드다. 나머지 3개는 재생 중 수집 때와 조금 다르게 진행됐다.

영상 · 실제 행동(왼쪽) 대 TT 생성 행동(오른쪽)

모두 데이터에서 넘어지지 않은 에피소드다. 같은 형상과 같은 시작 자세에서 출발한다. MuJoCo 3D 렌더링(GPU EGL)이다. 카메라는 로봇을 따라가고, 넘어진 뒤에는 마지막 화면을 유지한다. 주황 선은 로봇이 실제로 간 길이다.

확인 2 · 실제 행동을 줘도 움직임을 맞히는가

넘어지지 않은 에피소드 100개에서 TT 예측과 실제 기록의 차이. 비교 기준은 "로봇이 시작 자세 그대로 멈춰 있다"는 예측이다. TT가 쓸모 있으려면 이 기준보다 오차가 작아야 한다.

  • 로봇이 넘어지지 않으려면 몸통과 발의 관계가 맞아야 한다. 몸통 예측이 틀리면 그 예측을 바탕으로 만든 행동도 균형을 잃는다. 확인 1의 결과와 맞아떨어진다.

다음에 확인할 것

  • 몸통 위치 표현: 지금은 창마다 절대 위치(abs)로 학습한다. 한 step 변화량(delta)으로 바꾸면 몸통 이동 예측이 나아지는지 본다.
  • 생성 단계 수: 빠른 확인을 위해 DDIM 5 step으로 학습했다. 단계를 늘리면 생성 행동의 품질이 나아지는지 본다.
  • 창 경계: 64 step 창을 이어 붙이는 지점에서 행동이 튀는지 확인한다.
  • 넘어진 데이터: 학습 데이터의 약 64%가 넘어지는 에피소드다. 넘어진 뒤 구간을 빼고 학습할지 검토한다.

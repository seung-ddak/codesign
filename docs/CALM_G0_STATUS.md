# G0 검증 상태

기준: `CALM_EXPERIMENT_CHECKLIST.md`. 현재 G0는 FAIL이며, G1~G8은 선행 단계 미통과로 BLOCKED이다. 기존 V7 실험을 새 경로의 통과 증거로 사용하지 않는다.

## 현재 결과

- 정확한 HLC 설정 `a1_heading_lat_up_c8_hit2.yaml`, `hrl_a1_heading_lat31zs.yaml`로 새 실행 1회: 0.30초, 9스텝에 종료. 중간 초기화 없음. G0 통과 0회, 실패 1회.
- 상태 10개와 행동 9개의 시간 대응, 상태·행동·목표각·잠재벡터 유한성 확인. HLC 입력 351차원, LLC 입력 343차원, 잠재벡터 64차원, 관절 행동 12차원.
- 직접 종료 조건은 무릎 높이 제한 3프레임이다. 종료를 모두 몸통 전복으로 해석하면 안 된다.
- 실제 영상, 이동 궤적, 명령 대비 속도·방향, 관절각·힘 센서·목표각 그래프를 저장했다. 힘 센서값은 순수한 구동 토크로 검증되지 않았다.
- 보고서: `runs/calm_reference/g0_checklist_audit_final/report.html`.

## 확인되지 않은 내용

낮은 무릎 동작을 만드는 직접 원인이 정책 학습 상태인지, 제공된 코드와 학습 당시 환경 사이의 차이인지 아직 확정되지 않았다. 원래 정상 실행 환경의 버전·관측·행동 처리를 대조해야 한다. 종료 조건이나 이득을 완화해서 통과 처리하지 않는다.

초기 자세의 전체 충돌 형상 관통 검사는 미완료이며, 10초 회전·횡이동·정지 구간은 조기 종료로 실행하지 못했다.

## 코드와 다음 단계

- `verify_hlc.py`: 원본 hit2/31zs 설정, 관측 보정 기본 끔, 새 출력 경로 강제, 설정·소스·체크포인트 해시 기록. 영상 오류 시에도 부분 상태·행동을 보존한다.
- `diagnose_llc.py`: 최초 종료와 초기화 동작을 별도 측정한다. `--warmup`, `--sync-reset`, `--cpu-physics`는 원본 기준 실험과 분리한 원인 진단용이다.
- `reset_observations.py`: 초기 관측 보정 실험용이다. 원본 파일에는 적용하지 않았으며 전도 해결책으로 승인되지 않았다.
- `run_native.py`: 원본 실행기와 정확한 설정을 연결한다. 관측 보정은 명시적으로 요청할 때만 적용한다.
- `report_gates.py`: 연속 생존만으로 PASS를 부여하지 않고, 미완료 평가와 실행 오류를 구분한다.

후속 로봇 교체 초안은 `runs/calm_reference/deferred_native_a1/`에 보존하고 기존 PPO 학습·평가·수집 경로에 연결하지 않았다. 원본 충돌 형상에는 현재 MJX JAX 경로가 지원하지 않는 원통–상자 조합도 있어, 모델이 CPU에서 생성됐다는 이유로 MJX 사용 가능하다고 보고하지 않는다.

우선 G0 원본 정책의 명령 반응부터 확인한다. G3 대상 형상과 이후 학습 확장은 그 이후에 진행한다.

## 스폰·자기 충돌 비교에서 추가로 확인한 원인

정책·참고 모션·낙상 초기 상태 생성을 제외하고, 원본 `Humanoid` 자산 로더와 PD 제어만 사용해 기본 자세 유지 실험을 했다.

- 원본 자기 충돌 필터 0: 기본 자세에서도 2초 안에 뒤집힘. 최종 몸통 높이 약 0.057m, 몸통 위쪽 성분 최솟값 약 -1.
- 진단용 자기 충돌 필터 1: 같은 기본 자세와 이득에서 2초 동안 미전복. 최종 몸통 높이 약 0.291m, 위쪽 성분 최솟값 약 0.991.
- 같은 변경을 HLC와 LLC에 적용: 중간 종료·초기화 없이 10초 수행. 속도 오차 약 0.108m/s, 방향 오차 평균 약 2.11도, 정지 구간 평균 속도 약 0.049m/s.
- 같은 변경을 LLC 31개 환경에 적용: 관측 준비 스텝을 포함한 동일 비교에서 2초 내 종료 25개가 0개로 감소. 이것을 31개 모션의 정확한 추종 성공으로 해석하지 않는다.

현재 실행의 자기 충돌 설정이 조기 불안정에 영향을 준다는 통제 비교 증거다. 앞서 원인을 정책이나 초기 관측만으로 좁힌 해석을 수정한다. 정확한 충돌 몸체 조합과 원래 학습 환경의 충돌 필터는 아직 확인하지 않았다.

원본 파일과 종료 조건은 수정하지 않았다. `--disable-self-collision`을 지정한 별도 실행에서만 필터를 바꾼다. 원본 조건의 G0는 FAIL이며, 변경 조건의 실행은 연속 동작과 명령 반응을 확인했지만 학습 당시 조건과의 일치가 미확인이라 최종 판정은 BLOCKED로 남긴다. G1 이후 수집·학습은 시작하지 않았다.

비교 영상: `runs/calm_reference/spawn_root_cause_comparison/report.html`.

뷰어에서 같은 진단 조건 확인:

```bash
cd /home/cgr-ugrad-2026/quad_ws/codesign-calm
LD_LIBRARY_PATH=/home/cgr-ugrad-2026/miniconda3/envs/rlgpu/lib \
  ../external/a1-calm-main/.venv/bin/python code/motion_tracking/calm/run_native.py \
  hlc --disable-self-collision
```

LLC만 보려면 `hlc`를 `llc`로 바꾼다. 이 명령은 원본 실행기를 호출하되 자기 충돌 설정을 명시적으로 변경하는 진단용 명령이다.

# CALM 10,000 모션 공용 PPO 수집 설정

설정은 `configs/shared_calm_10000_plan.yaml`에 보관한다. 현재 실행 중인 형상별 PPO 수집은 변경하지 않았다. 이 파일은 실험 명세이며 기존 Hydra trainer에 직접 전달하는 실행 파일이 아니다.

## 형상 수

e000 실제 길이 ±20%에서 활성 토큰은 2,3,4,9,10의 5개다. 나머지는 제거된 팔 또는 실제 기준값 0인 위치·각도이므로 고정한다. 학습 형상 200개와 별도 검증 형상 20개를 권한다. 200개는 최적값으로 검증된 숫자가 아니라 개별 효과와 복합 효과를 분리해 관찰할 수 있는 초기 예산이다.

학습 구성: 기준 1 + 단일 변화 40(각 토큰 ±5/10/15/20%) + 두 토큰의 극단 조합 40(10쌍×부호4개) + 다섯 토큰 극단 조합 32 + 내부 복합 87(3·4·5토큰 각29개). 합계200개다. 검증20개는 학습에 없는 연속적인 내부 조합으로 구성한다. 검증 형상이 충분히 추종되지 않으면 형상 수만 늘리기 전에 학습량·보상·리타겟 가능성을 구분해 분석한다.

100개는 초기 실행·시간 검증용으로 유용하지만 위 구성의 극단과 내부 영역을 함께 충분히 확보하기에는 빠듯하다. 5차원 공간 전체를 200개로 완전히 덮었다고 주장하지 않는다.

## 하나의 정책과 모든 모션

형상마다 독립 정책을 만들지 않는다. E와 미래 reference를 관측하는 하나의 공유 actor/critic을 사용한다. 원본10,000개를 모두 정책 학습에 사용한다. 그러므로 별도형상 검증은 가능하지만 보지 않은 원본모션에 대한 PPO 일반화라고 해석하면 안 된다.

메모리에는 학습형상4개, 평가형상1개, 모션128개만 적재한다. 과거 모션25% 재방문은128개 슬롯의 일부를 사용하며 신규모션 순회를 대체하지 않는다. 모션·형상 묶음을 교체할 때 정책·critic·normalizer·optimizer 학습 상태를 이어가야 한다. 단순 순차 학습만 하면 이전 모션을 잊을 수 있으므로 실제 재방문 성능을 측정한다. XLA 재컴파일과 CPU 리타겟팅 시간도 별도로 기록한다.

현재 `multi_design.build_bank`는 resident형상마다 같은 모션과 길이가 있어야 한다. 기존 `validate_split`는 평가 모션의 학습모션 중복도 거부한다. 모든 원본을 학습하는 이 실험은 평가형상만 분리한다고 명시하는 별도 경로가 필요하다. 현재 checkpoint 복구는 정책·value·normalizer를 복원하지만 optimizer 전체 상태를 이어가는 구조는 아니다. 위 세 가지 실행 경로는 추가 구현 전이며 이 명세만으로 학습을 시작할 수 없다.

## 학습 예산

총2억 환경전이를 초기 예산으로 잡고2,500만 전이마다 범위별 성능·실제 데이터 커버리지를 재평가한다. 환경64, minibatch batch64, unroll24, minibatch4이면 PPO 반복당6,144전이다. 총예산을 한 연속실행으로 환산하면32,553반복,200,005,632전이다. 반복마다 같은데이터를4회 재사용하고 각회4개미니배치로최적화한다. 모션묶음별 예산 반올림에 따라 실제합계는 달라질 수 있다. 저장주기983,040전이, 진행지표98,304전이 간격을 목표로 한다. 주기는4의 배수인 PPO 반복 수에 맞춘 것이다.

이 예산은 수렴 보장이 아니다. 먼저1개 resident묶음에서 VRAM·처리속도·최적화안정성·실제모션노출카운터를 확인하고 전체예상시간을 측정한다. 이전형상별실험 시간으로 전체시간을 확정하지 않는다.

## TT용 수집 목표와 검증

각원본을 서로다른학습형상4개에서실행해40,000개원본-형상쌍을 확보한다. 각쌍3회로 총120,000개episode를 목표로한다. 첫프레임기본상태, 첫프레임작은관절상태변화, 앞절반내무작위RSI시작을 구분한다. deterministic정책과동일초기상태에서 seed만바꾸는것은새로운데이터로세지않는다.

원본모션마다기본상태의전체길이실행시도가포함되어야한다. 앞부분RSI수집으로 전체길이시도를대체하지않는다. 낙상까지의유효전이도보존하고 정확한시간축·행동과다음상태정합성을검사한다. 모든원본에유효기록이있고각원본이서로다른4형상에배정됐는지 실제출력으로검증한다. episode수120,000만으로다양성이확보됐다고판정하지않는다.

10·20초 비율과 RSI부분실행을 감안하면 낙상전의 잠재적 전이는 대략5,200만개다(기본2회+평균75%길이RSI1회). 이는 중복없는독립표본수나성공전이수가아니며 낙상과상태유사도로 실제유효양은줄어든다. 파일압축크기와디스크필요량은 파일럿으로 측정한다.

낙상률50%이하를수집통과로쓰되초과형상도유효기록을유지하고다음으로진행한다. TT학습시원본모션group을기준으로분리하고별도검증형상성능도보고한다. 정밀추종·낙상률·정지구간·중복도·속도·회전·높이·관절속도·접지·행동분포를함께보고, 실패데이터가낙상직전상태에편중되지않는지확인한다.

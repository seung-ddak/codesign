# V100 48시간 수집 경로 검증

V100 실기 검증은 하지 않았다. 로컬 RTX 4070 SUPER에서 소규모 기능 검사와 CPU 테스트를 수행했다. 예시 보고서는 [한국어 대시보드](examples/shared_calm_v100_pilot_report.html)에서 볼 수 있다.

- 원본 모션 4개, 학습 형상 2개, 검증 형상 1개.
- 공유 PPO 학습 2,048전이, 두 번의 묶음 방문에서 Adam·정규화·정책·가치망·누적 step 재개 확인.
- 실제 rollout 16개, 유효 전이 1,456개, 낙상 16개.
- 원본 커버리지 4/4, 실제 모션·형상 쌍 8/8, 두 시작 조건 8쌍.
- 목표 시간 구간 커버리지 59.3%. 이는 목표 수행 정확도와 다르다.
- 시작 상태 중복 0개, 형식 오류 0개. 모든 저장 행동의 히스토그램을 NPZ 원시값으로 다시 계산해 보고서와 일치함을 확인했다.
- Chrome에서 한국어 카드·축·제목과 실제 지표 렌더링 확인. 예시에는 작은 기능 검사 자료임을 명시했다.

이 결과는 실행·기록 경로 검사이며 추종 정책의 수렴, V100 처리 속도, 48시간 내 40,000개 확보 또는 TT 생성 품질을 입증하지 않는다. 전체 테스트 187개가 통과했다. 실제 파일럿 16개 rollout을 TT 특징 (16, 32, 54)와 E (16, 13)으로 로딩했고, 원본 그룹 4개 유지 및 개입 쌍 0개를 확인했다.

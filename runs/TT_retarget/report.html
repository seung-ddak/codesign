TT 4 형상 리타겟

요약

  • A1 레퍼런스 (artifacts/pd_replay/) → TT 4 형상 IK 리타겟 (pd_replay.py --retarget). 발 목표 = TT 엉덩이 + s·(A1 발 − A1 엉덩이), s = 다리 길이 비 0.938, base 자세 A1 그대로, base z 는 딛은 발이 바닥에 닿게 → foot_lock (mink IK).
  • 계단은 고정 위치라 보폭을 줄이지 않음 (xy 배율 1). 점프 공중 구간은 A1 높이 × s + 앞뒤 접지 오프셋 보간.
  • 전환 3 종 (2026-10-12): A1 두 구간을 0.5 s smoothstep 블렌딩 → 접지 재판정 → foot_lock (pd_replay.py --transitions) → 같은 리타겟. 이음새 관절 변화 ≤ 7°/프레임.
  • 물리 불가능 프레임 (역동역학 검사, 유령 힘 > 체중 10%) 이 TT 에서 A1 보다 크다: A1 평균 7%, TT 평균 29% (walk·trot 19~82%, 평균 41%). TT 다리 질량 비중 79% 탓, 레퍼런스 쪽 한계.
  • 데이터 위치: 이 폴더 runs/TT_retarget/<형상>/<모션>.npz. 학습 설정이 쓰는 artifacts/retarget_tt 는 이 폴더로의 링크.

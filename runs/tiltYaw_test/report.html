tiltYaw 문제 테스트

요약

  • 문제: TT 00000010 26 모션 학습 (TT_tracking/tt00000010_try2) 에서 tiltYaw 만 넘어짐.
  • 원인 ①: 넘어짐 penalty −10 이 tracking weight ×10 대비 너무 작아 넘어지는 쪽이 이득 → −100 으로 올려 해결 (TT_tracking/tt00000010_try3, 26/26 완주).
  • 원인 ②: 형상 의존. 앞·뒤 무릎이 다른 00000010·00000001 만 tiltYaw 완주, 같은 방향 00000000·00000011 은 넘어짐. 리타겟 좌표 변환 탓 아님 (A1 원본도 추종 최악). kp 100·발 고정 없는 reference 로도 해결 안 됨.
  • 결정 (사용자): tiltYaw 를 학습 모션에서 제외 → TT_tracking/tt_js100M 부터 적용.

좌표 변환 점검 (사용자 요청)

  • 무릎 방향: 00000011 이 A1 과 같이 뒤로 꺾임 (무릎 위치 −0.146 vs A1 −0.157), 00000000 은 반대. 리타겟 관절각은 4 형상 모두 무릎 방향이 끝까지 유지되고 프레임 간 튐 없음 (최대 0.09 rad).
  • 정책 없이 reference 관절각을 PD 목표로 재생: 4 형상 모두 tiltYaw 완주, 00000011 자세 오차 21.7° (00000001 21.0° 와 비슷).
  • 대조: 좌표 변환이 전혀 없는 A1 몸 + 원본 reference 도 같은 조건에서 tiltYaw 추종이 가장 나쁘다 (관절 33.7°, 발 20.5 cm, 자세 18.8°). → 00000011 의 부진은 리타겟 좌표 변환 탓이 아니다.

관찰

  • 앞·뒤 무릎이 서로 다른 형상(00000010, 00000001)은 비교적 잘 따라가고, 네 무릎이 같은 방향인 형상(00000000, 00000011, A1)은 넘어지거나(TT) 크게 벗어난다(A1).
  • 학습 곡선: 네 형상 모두 초반에 넘어지는 쪽으로 갔다가, 다른 무릎 형상 둘만 8~12M step 에서 넘어짐 0% 로 회복했다. 같은 무릎 형상 둘은 20M 까지 넘어짐 77~96%.
  • 완주한 형상도 몸통을 덜 비튼다 (관절 8.6~11.3°, 자세 5.0~8.3°). 시드 1 개·20M step 결과라 형상 차이로 단정하려면 시드 반복이 필요하다.

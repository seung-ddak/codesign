# CALM 1,000형상 × 100모션 dynamics 수집

원본은 `../calm_motion_10,000/dataset`이다. **10,000개 통과 완료 후** 원본 해시를 고정하고 배정한다. 대기 중에는 `status.json`, 배정 완료 후에는 `manifest.json`을 확인한다. 미리 검토할 형상은 `designs.json`, 모션ID 배정은 `assignment_preview.json`에 있으며, 원본해시는10,000개 완료 후 확정한다.

## 배정

- 총1,000형상, 형상당100개, 총100,000개 실제 정책 실행 episode 목표.
- 공통30개: K=1~12가 모두 포함되도록 고정 선정. 모든 형상이 동일한 원본30개를 트래킹.
- 나머지70개: 공통30개와 겹치지 않으며 한 형상 안에서도 중복 없음.
- 공통을 뺀9,970개 원본은 전체70,000개 추가 배정에서 각각7~8회 사용. 형상별70개 묶음은 서로 다르게 구성.
- 형상: TT topology `00000011`, e000(E=0.5)의 실제 길이 기준 ±20%. 기준형상1개 + 단일토큰변경200개 + 복수토큰변경799개. 정규화토큰에 일괄 ±0.2를 더하는 방식은 사용하지 않는다.
- 원본과 배정표는 고정한다. 실패했다고 모션이나 형상을 임의로 바꾸지 않는다.

공통 모션은 **같은 reference**를 뜻한다. 각 형상의 초기 자세는 리타겟되고 실제 제어 행동은 PPO 피드백으로 달라진다. 따라서 동일 S₀·동일 A에서 E만 바꾸는 반사실 개입 쌍은 아니다.

## 실행

1. 원본10,000개 완료와 최종 보고서·대표영상5개 완성을 기다린 후 manifest·designs.json 작성.
2. CALM 원본 URDF 운동학과 맞춰30Hz 상태를50Hz reference로 변환. 관절 이름으로 순서를 재배열하고 quaternion은xyzw→wxyz, 회전은Slerp로 보간한다.
3. 형상별100개 reference를 기존 발 기반 IK와 역동역학 도구로 리타겟팅. E 정합성·유한값·관절 한계를 검사한다.
4. 형상별PPO 정책 하나가 해당100개 모션을 학습. single-design 모델에 해당E를 명시적으로 주입한다. 초기 학습 예산은형상당5,242,880전이,64병렬 환경이며 수렴 보장은 아니다. 모션당 개별 정책100개를 학습하는 방식은 아니다.
5. 각 reference 첫 상태에서 해당정책으로10초/20초 실제 물리 실행을1회 기록한다. 정밀 추종 성공과 실제 실행 완료는 구분하며, 낙상 episode도 마지막 유효 전이까지 보존한다.

`jobs/<design>/state.json`에 단계별 진행, `train.log`·`rollout.log`에 실행 로그를 남긴다. 중단 후 같은 명령을 실행하면 완료 단계는 건너뛴다. 중간학습 체크포인트가 있으면 가중치·optimizer를 불러 추가 예산을 학습한다. 환경·난수까지 같은 시점으로 복구하는 정확 재개는 아니다. 한 형상에서 실패하면 기록하고 다음 형상을 진행하며 전체 상태는incomplete로 표시한다.

```bash
# codesign 디렉터리, 기존 queue 서비스가 실행 중이지 않을 때만 실행
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 XLA_PYTHON_CLIENT_PREALLOCATE=false \
../transformer-transformer/.venv/bin/python -u code/motion_tracking/run_calm_dynamics.py \
  --source 'runs/calm_motion_10,000/dataset' --out runs/calm_dynamics_1000x100 --wait-for-source
```

전체큐는 사용자systemd `calm-dynamics-1000x100.service`로 대화와 독립적으로 실행한다. 소스 수집과 최종 보고서가 끝나기 전에는 대기하며1,000형상 작업을 순차 실행한다. 잘못된 단계가 무한 반복되지 않도록 정상적인실패 종료는 자동 재시도하지 않는다. 소스·학습 예산·배정표가 바뀌면 기존job의 재개를 거부한다.

## 출력과 TT 연결

`rollouts/<design>/primitive_seed0.npz`:
- 실제qpos/qvel/contact: `(100,T+1,...)`
- 실제action·PD target_q·valid: `(100,T,...)`
- E·source_motion_id·common·group_id·fell·termination·checkpoint
- 모션별 관절각·몸통 위치 추종RMSE

T는해당파일의 최대길이(50Hz에서500또는1000전이)이며 짧은모션 종료 뒤와 낙상 뒤는valid=false다. 기존TT rollout loader 형식과 맞춘다. source group_id는 원본해시·모션ID·시작프레임을 기준으로 형상간 동일하게 유지해, 같은 원본의 복제본이 TT train/val 양쪽에 나뉘지 않도록 한다. 이후 별도의미학습형상 평가도 분리해야 한다.

이전실험을 재현하는 용도가 아니라 새 대규모수집이다. 100,000개가 모두 정밀모션트래킹에 성공했다고 자동 판정하지 않는다. 실제결과의 완료율·낙상·추종오차를 확인해야 한다.

## 대규모 실행 전 기준 형상 점검

짧은 실행 검증은65,536학습전이 후 실제정책 실행39스텝에서 낙상했다. 실행경로 확인이며 트래킹 성공이 아니다. 따라서 기준형상e0000의100모션을 먼저 본 학습 예산으로 실행하고,90% 이상이 끝까지 실행되며 관절RMSE≤5도·몸통위치RMSE≤3cm를 충족해야 나머지999형상으로 확장한다. 미달 시 `tracking_quality_gate_not_met`로 기록하고 대기 작업을 멈춘다. 원본실패데이터는 보존하고 기준을 느슨하게 바꾸지 않는다.

검증 기록: 전체CPU 테스트158개 통과 후, 최종 배정·모델E적용·기준형상 실패 시 확장중단 검사7개 통과. 실제CALM 원본 1개를501상태 reference로 변환하고 기준형상으로 리타겟팅해 발오차0.2mm·관절한계위반0·역동역학불량0%를 기록했다. 검증용PPO65,536전이 학습과 실제39개 유효전이 저장을 확인했다. 검증 출력은 /tmp/calm-dynamics-validation에 있으며 본 수집 결과로 합산하지 않는다.

## 2026-11-05 VRAM 절약 수집 재개

학습 병렬 환경과 PPO batch_size를 각각256→64, 평가 환경을8→2로 줄였다. 총 학습 예산5,242,880전이와 형상당100모션은 유지한다. 실제 rollout은16개씩 순차 실행하고 마지막 묶음의 패딩 episode는 저장 전에 제거한다. episode 순서·source_motion_id·group_id와 원래100개 출력 형태를 유지한다. JIT 물리 함수는 묶음 간 재사용하며 기록은 즉시 CPU NumPy로 옮긴다.

학습·rollout 자식 프로세스는 `XLA_PYTHON_CLIENT_PREALLOCATE=true`, `XLA_PYTHON_CLIENT_MEM_FRACTION=0.60`으로 실행한다. 이는 JAX 메모리 풀 설정이며 CUDA 라이브러리·화면 표시 등 전체 GPU 사용량의 하드 제한은 아니다. 단계별 자식 프로세스 종료로 GPU 할당을 반환한다. 메모리가 부족하면 해당 단계는 실패 상태로 남으며 완료로 표시하지 않는다. 기준형상90% 정밀추종 통과 후에만 나머지 형상을 진행한다.

### 추가 메모리 절약 설정

첫60% 선할당 실행은 화면 포함약8.2GB를 예약하여 중지했다. 현재는 선할당을 끄고 JAX 풀 비율을35%로 낮추며, 학습 환경32개·batch32·평가1개·rollout8개씩 실행한다. 총 전이 수는 유지하지만 PPO 배치 구성이 바뀌어 학습 속도와 수렴 양상이 달라질 수 있다. 이전 시도의 로그·정책 폴더·protocol은 e0000 job의 `attempt_preallocation_*`에 보존했다. 저장된 학습 체크포인트가 없어 초기화부터 재시작한다. 풀 비율은 전체 VRAM의 하드 제한이 아니며 실제 측정은 `vram.csv`에 남긴다.

## 완료된 기준형상 PPO·rollout 결과 (50Hz)

이 폴더의 e0000 정책은 50Hz 제어로5,243,904전이를 학습했다. 100개 모션 실제 실행 중73개는 끝까지 수행,27개는 낙상했으며70,079개 유효전이를 저장했다. 정밀추종 통과는0개여서 나머지999개 형상은 실행하지 않았다. `rollouts/e0000/primitive_seed0.npz`에 성공·실패 모두 보존하고 valid 마스크로 구분한다. 관절RMSE 중앙값9.05도, 몸통위치RMSE 중앙값35.1cm다. `rollout_examples.html`에는 완료·실패 각1개 영상을 내장했다.

완료 정책 checkpoint는 `jobs/e0000/policy/wandb/offline-run-20261105_095955-zbd5k3mk/files/checkpoints/5243904`이며 Git ignore 대상이므로 `portability/` 검증 분할 묶음에 포함한다. 다른 PC에서는 SETUP.md의 restore 명령으로 복원한다.

현재 소스 코드는 이후 요청에 따라30Hz 제어·240Hz 물리 계산으로 수정되었다. 이50Hz 결과를 현재 소스로 그대로 재학습하면 protocol 불일치로 거부되며, 평가에는 checkpoint의 저장 설정을 사용해야 한다. 별도로 시작한30Hz 실험은 `../calm_dynamics_1000x100_30hz/`에 있으며 이 완료 결과와 혼합하지 않는다.

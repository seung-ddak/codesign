Diffusion 내부 reward-gradient guidance를 PPO로 치환

구현 및 실제 실행 검증 완료. task 성능 개선 검증은 아니다.

동결된 TT의 각 denoising 단계에서 PPO가 E·S·A의 epsilon 보정을 선택한다. reward 미분은 계산하지 않는다. 최종 E·A를 물리 실행한 보상으로 PPO를 학습했다. S0는 E의 안착 자세, 미래 S와 A는 공동 생성이다. 이전 task_rl_v1/v2의 별도 관절 제어 정책과 다르다.

실제 v16 twin checkpoint, 200 상태 프레임, 후보 2개, PPO 2update(학습 물리 episode4개·denoising 전이20개). 학습과 분리된 동일 평가 잡음으로 비교했다. unguided와 rl_before는 정확히 동일하다. rl_after는 E·S·A 모두 변경됐으며 gradient audit은 모두 false다.

실제 물리 실행 영상

학습 후 diffusion PPO 영상만 표시한다. 노란 선은 목표 중심선, 흰 선은 경계다. 지그재그는 진폭 0.3m·주기 2m·반폭 0.15m, 원형은 반지름 1m·반폭 0.3m다. 트랙 표시는 보상식의 guide_lines를 사용하며 충돌·물리에는 영향을 주지 않는다.

지그재그는 기존 저장 기록을 사용했다. 원형은 기존 기록이 없어 같은 조건(PPO 2update·학습 물리 episode4개·별도 평가 후보2개)으로 새로 학습·실행했다. 각 task의 PPO 정책은 별개다. 각 후보의 생성 E와 실제 물리 qpos로 재생하며, 4초 실제 속도다. 낙상 뒤에는 마지막 프레임을 유지한다. 위 비교 표는 지그재그 결과이며 원형 원자료는 아래 링크에 있다.

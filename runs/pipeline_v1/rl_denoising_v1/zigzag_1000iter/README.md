# 지그재그 RL 디노이징: 후보 8개, 100 iter

사용자 요청에 따라 기존 `zigzag_1000iter` 경로를 그대로 사용한다. 폴더명과 달리 현재 목표는 **100 iter**이며 후보 수는 **8개**다. 같은 seed 0으로 처음부터 학습한다. 디노이징 5단계, 상태 200개(최대 실제 실행 3.98초), 기존 보상·학습률·엔트로피 설정을 유지한다.

이전 후보 2개·1,000 iter 실행은 300 iter에서 중지했고, 파일 전체를 상위 폴더의 `zigzag_1000iter_stopped_300updates.tar.gz`에 압축하여 원본 해시와 일치함을 확인했다.

현재 로그: `../zigzag_batch8_100iter.log`, 상세 지표: `training.jsonl`, 정책: `policy.pt`. 완료 시 `summary.json`에 평가 결과를 저장한다. 상위 `report.html`은 현재 후보 8개·100 iter 완료 결과로 갱신했다. 전체 8개 평가표와 후보 0·1의 최신 영상이 포함된다.

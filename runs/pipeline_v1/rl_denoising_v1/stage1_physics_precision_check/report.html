1단계: 학습·평가 환경 비교

별도 MJX 평가 경로와의 완전한 일치는 확인되지 않았습니다.

같은 입력을 주어도 일부 움직임에서 사전에 정한 차이 기준을 넘었습니다. 이 결과만으로 정책이나 평가 코드 중 어느 쪽이 잘못됐는지 확정할 수는 없습니다.

그렇게 판단한 근거

  • 현재 CPU 학습·보고서 평가 경로는 모든 비교 사례에서 동일하게 재현됐습니다.
  • 별도 MJX 경로의 실제 움직임 비교 1개 중 0개는 허용 오차 이내였고, 1개는 차이 기준을 넘었습니다.

그래서 다음에 할 일

차이가 시작되는 제어 시점과 접촉·물리 계산을 추가로 비교해야 합니다.

남아 있는 문제

이전 생성 행동 한 사례는 처음 2초 동안 몸통 자세 차이가 최대 3.29도로, 사전 기준 2도를 넘었습니다.

따라서 별도 MJX 평가 경로까지 완전히 같다고 결론 내리지는 않습니다. 현재 보고서의 CPU 평가에서 발생한 즉시 낙상과는 구분해야 합니다.

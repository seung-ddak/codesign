0단계 기록 확인 결과

새 기록 방식은 검증을 통과했고, 기존 자료는 일부만 확인할 수 있습니다.

재실행한 보상은 기록과 일치했습니다. 기존 실험은 매회 학습 궤적이 없어 완전 검증으로 판단하지 않습니다. 기록이 맞는다는 것은 과제 수행이 잘됐다는 뜻은 아닙니다.

같은 E와 생성 행동을 물리 환경에 다시 적용해 저장 결과와 비교했습니다. 새 기록은 저장된 상태·모터 목표·힘에서 보상 항목도 다시 계산합니다. 부분 확인은 확인 가능한 자료에서 불일치가 없지만 전체 학습 궤적이나 상세 기록이 없다는 뜻입니다. 재실행 건수에는 같은 결과를 별도로 저장한 중복 기록도 포함합니다. 통과는 과제 수행 성공을 의미하지 않습니다.

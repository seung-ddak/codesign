# PD 안착 상태 추가 입력 비교

실제 초기 상태 s0와 정답 궤적을 바꾸지 않고, 형상 E에서 계산한 home 1초 시뮬레이션 상태 g(E)를 추가 입력으로 제공한다. 기존 형상 표현보다 안 본 형상에서 속도 예측이 좋아지는지 검증한다.

## 실행

저장소 루트에서 `bash runs/pipeline_v1/regression_rest_features/run.sh`.
Python 환경은 `../transformer-transformer/.venv`. CPU만 사용하고 연산 라이브러리 스레드는 2개로 제한한다. 임시 파일과 캐시는 /home의 작업 폴더에 저장한다. 데이터 재수집, TT 재학습, task 생성은 실행하지 않는다.

## 비교 및 판정

- s0_A: 실제 초기 상태 + 행동
- E_s0_A: 기존 형상 좌표 + 실제 초기 상태 + 행동
- g_s0_A: home 1초 상태 + 실제 초기 상태 + 행동 (표현 교체 대조군)
- E_g_s0_A: 기존 형상 좌표 + home 1초 상태 + 실제 초기 상태 + 행동 (주 비교군)

PD kp200 동일 16형상, 동일 생존 그룹, 동일 4-fold, 동일 학습 설정과 seed 0/1/2를 사용한다. 주 지표는 안 본 형상의 1초 전진 평균 속도. 주 비교군의 B0 대비 오차 감소 20% 이상, 형상 효과 부호 80% 이상 일치, 기존 E_s0_A보다 오차 감소가 모두 성립하면 통과다. B0는 같은 모션·시작 그룹 내 학습 형상의 평균이다. `conditions.json`은 결과 확인 전 저장했다.

동일 모션 안에서 안 본 시작 프레임 평가도 별도로 기록한다. 새로운 모션에 대한 일반화 시험은 아니다. seed별·fold별 성능과 원단위 예측을 저장한다. 추가 입력에 따른 첫 층 파라미터 수 증가는 통제하지 않았으므로 작은 성능 변화만으로 물리 표현의 우월성을 단정하지 않는다.

## 안착 상태 계산

`prepare.py`는 `generate_task.py`에서 `rest_s0_of` 함수 정의만 AST로 읽어 실행한다. 이로써 기존의 모델 설정·접촉 처리·home 높이 정렬·1초 MuJoCo CPU stepping·42차원 특징 계산을 그대로 사용하며, 원본 모듈의 TT 로딩·생성 실행을 피한다. 실행 코드와 설정의 SHA-256은 `rest_provenance.json`에 저장한다.

1초 후에도 모든 형상이 정지·접촉 상태라는 보장은 없다. 접촉과 자세를 기록하고 이를 이유로 형상이나 샘플을 제외하지 않는다. 이번 실험의 g(E)는 평형 상태의 보장된 해가 아니라 기존 함수가 반환하는 1초 상태다.

PD의 행동은 형상별 리타겟된 목표 관절각이므로, 이 실험은 같은 행동을 고정한 형상 교체 인과 검증이 아니다. 생존 그룹만 사용하므로 낙상 예측 성능도 평가하지 않는다.

`checkpoints/`는 현재 고정 조건의 분할별·seed별 예측 캐시다. 같은 명령을 재실행하면 완료된 예측을 재사용한다. 입력 데이터·학습 설정·코드를 바꿀 때는 새 결과 폴더를 사용해야 한다. 저장 코드의 경로 직렬화 오류를 수정해 재실행했으며, 이를 모델 성능 실패로 집계하지 않는다.

## 결과 (2026-11-02)

[사실] 사전 기준 미달. 안 본 형상 vx RMSE는 기존 E+s0+A 0.10886 → E+g+s0+A 0.11829 m/s로 8.7% 악화. 형상 효과 부호는 66.7% → 63.6%, B0 대비 오차 감소는 -20.9%로 목표 +20% 미달. 형상 분할 4개와 seed 3개 모두 추가 입력 조건이 악화. g+s0+A도 0.12684로 기존 E 표현보다 나쁨.

[판단] 이 조건에서 TT 입력 확장을 지지하지 않음. 입력 표현·학습 방식·1초 상태의 불안정성 중 원인은 분리하지 못했음.

[사실] 완료 실행 15.8분. 관련 검증14개 통과, 원단위 예측에서 RMSE 재계산·입력 해시 일치 확인. RAM 여유 최소17.6GiB, 결과 약2.6MiB. 결과 그래프와 전체 평가 지표는 report.html, results.json, summary.json에 있음.

[사실] 같은 모션의 안 본 시작 프레임 보조 평가에서는 vx 오차 0.2330 → 0.2267 m/s로 2.7% 감소했음. 안 본 형상 주 평가의 실패 판정은 유지함.

# v13 실제 task 성능 검증

기존 지그재그·원형 task의 형상 고정 생성과 형상·행동 공동 생성을 4초·10초 실제 MJX로 검증한다. 모델 학습은 다시 하지 않는다.

1. v13: unguided2초16후보, 4초 task별 고정형상16×4후보·공동생성16후보, 10초도 같은 규모. v12: 기존4초 결과는 원본 해시를 확인해 재사용하고, 10초 공동생성16후보씩을 새로 실행한다. 신규 MJX후보는 총368개다. v12의 10초 고정형상64후보 격자는 추가하지 않는다.
2. seed0, guidance10(기본2초는0), kp200, 같은 실제 home1초 초기화, 같은보상·정규화·생성설정이다. 추가 geometry보정·replan·expert보행 워밍업은 사용하지 않는다. 형상별 실제 초기 상태는 E에 따라 달라진다.
3. 기존 기준은 예측 형상 효과 permutation p<.05, 실제/예측 형상 평균보상 순위상관>.6, unguided2초 경로 차 중앙값<.15m다. 유효한 보상이 없는 형상이 있으면 전체16형상 순위는 계산불가이며, 일부 형상만으로 계산한 보조상관으로 통과를 만들지 않는다.
4. 10초에는 새 성공 기준을 임의로 만들지 않는다. 전체생존, signed진행, 보상, 트랙 이탈, 예측으로 선택한 후보의 실제성능을 직접 보고한다. 생존+양수진행은 보조 진단이며 task성공률 정의가 아니다. 실제보상 최고후보는 사후선택이라 TT의 선택성능과 구분한다.
5. 지그재그 진행 단위는m, 원형은바퀴(laps)다. 실제 유효 프레임만으로 트랙내 비율을 계산하므로 낙상여부와 함께 해석한다. 낙상후는 유효경로에서 제외하지만 그 후보를 생존율·진행 중앙값에서 임의로 버리지 않는다.

실행은 GPU가 보이는 일반 터미널의 저장소 루트에서 한다.

```bash
TMPDIR="$PWD/.runtime/tmp" ../transformer-transformer/.venv/bin/python -u runs/pipeline_v1/fast_mode24_v13_group_loss/evaluation_tasks/run_tasks.py
```

완료한 단계는 conditions fingerprint 확인 후 재사용한다. 작업별 로그·status.json·resources.jsonl로 진행을 확인한다. CPU2개, Torch GPU25%, JAX pool40%, preallocation해제, /home 임시파일·캐시를 사용한다. 자원 여유가 연속2번 기준미달이면 이번 worker만 중단한다. 조건·코드·모델·재사용 v12 원본의 해시를 확인하며, 원본 결과는 덮어쓰지 않는다.

v13 공동생성은 실제영상도 기록한다. v12 10초는 수치·원래 예측·실제상태·mask·형상정의를 보관하고 영상은 만들지 않는다. 이번 출력에서만 .mjb 컴파일 중복본을 정리하며, 같은이름의 형상JSON과 build_model 재생성 정의는 보존한다.

모든 단계가 완료되면 summarize_tasks.py가 전체크기·유효값·조건·표본수·원본해시를 검증하고 report.html, summary.json, results.json, comparison.png, artifact_sha256.json을 만든다. 학습보고서는 상위 report.html이며, task보고서는 이 폴더의 report.html로 구분한다.

범위는 기존 두 task·seed0이다. 새 장애물 task·새 학습 seed 반복은 이번 평가에 포함하지 않는다.

4초와10초는 해당 길이의 전체 보상을 사용해 별도로 생성한 계획이다. 같은4초 행동의 뒤를 단순히 연장한 비교가 아니다. 시간 길이에 따른 차이에는 생성 계획 자체의 변화도 포함된다.

2026-11-03 평가 완료: 생성후보368개, 실제실행346개, 초기물리제외22개. v13 실제영상61개. 전체파일해시·크기·유효수치·조건검증통과. 기존4초기준은 두 task 모두 통과하지 못했다. 전형상 순위는 유한보상없는1형상 때문에 계산불가, 유한15형상의 보조순위도 zigzag0.171/circle-0.429로 낮았다. 10초 공동생성은 zigzag생존5/16·진행중앙값-0.754m, circle8/16·-0.0339바퀴였다. v12 10초는 각각8/16·-0.0764m,4/16·-0.0559바퀴. 짧은실행생존일부개선이 전체task성공으로 이어지지 않았다.

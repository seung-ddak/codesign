이번에 확인된 내용

  • 하한 포화는 전체 8개 중 2개입니다. 나머지 6개도 실패했으므로 clamp 하한만으로 모든 물리 실패를 설명할 수 없습니다.
  • Scale 0·1의 후보 3은 관통하지 않지만 접촉 발이 0개라 Gate를 통과하지 못했습니다. 접촉이 없는 이동 상태가 물리적으로 불가능하다는 일반적 결론이 아니라 현재 최소 2발 지지 조건에 따른 탈락입니다.
  • 나머지 후보는 발 또는 비발 관통으로 탈락했습니다. 초기 E·높이·관절각·접촉의 정합성이 여전히 병목입니다.
  • 한 번의 seed 0 batch 결과이며 생성 분포 전체의 유효율을 추정한 결과는 아닙니다. 이전 1후보 실험과 동일 seed·동일 checkpoint여서 새 후보 0은 독립 반복이 아닙니다.
  • 예측 reward·gradient가 존재해도 실제 수행 성능은 아직 판정할 수 없습니다. 조건대로 추가 자동 반복과 10초 실행은 진행하지 않았습니다.

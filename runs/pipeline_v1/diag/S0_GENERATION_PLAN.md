# 보류 실험: 생성한 E–S₀의 물리적 유효성

목적: TT가 만든 형상 E가 MJX에서 시작할 수 없는 이유가 S₀의 높이·관절각·접촉과 E의 조합 때문인지 확인한다. 이 실험은 wide16 expert 재학습 후 진행한다.

1. 기존 `h32_try6` mode 4 생성 결과의 첫 window에서 E와 S₀를 꺼낸다. 같은 seed의 생성 결과를 반복 평가하지 않는다.
2. E와 S₀를 MJX qpos/qvel로 복원해 초기 관절 한계, 비발 충돌·지면 관통, 실제 발 접촉, 짧은 무명령 안정성을 검사한다. 네 발 접지를 강제로 맞추거나 높이를 사후 보정하지 않는다.
3. 학습 데이터의 형상별 S₀ 높이·관절각·접촉 분포와 생성 쌍을 비교한다. 유효·무효 건수와 실패 이유를 E별로 저장한다.
4. 생성 E에 맞는 유효한 S₀를 제공했을 때의 MJX 실행도 함께 비교해, 시작 상태 실패와 이후 동역학 예측 실패를 분리한다.

판정: 생성 E–S₀의 초기 유효율과 짧은 생존율이 낮으면 S₀ 생성·제약 문제를 우선 해결한다. 초기 상태가 유효한데도 실행이 어긋나면 A→S 및 E→S 동역학 학습을 별도로 다룬다. 쌍별 D4는 같은 S₀·A를 넣은 제한된 공통 유효 영역의 평가이므로 이 진단을 대신하지 않는다.

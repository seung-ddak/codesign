실험 조건

  • TT 재학습 없음. 기존 16개 형상·19종 primitive Mode 2·4 / 3,000-update checkpoint 사용.
  • Zigzag reward · seed 0 · scale 0 대 scale 1 · 각 후보 1개 · 동일 초기 diffusion noise.
  • H=32, 겹치는 window 4개, diffusion 5단계. 하나의 E를 공유하며 전체 예측 구간 reward를 guidance에 사용.
  • 초기 XY·Yaw만 고정. E·나머지 S₀·S·A 공동 생성. 몸통 높이 보정 없음.
  • 100개 state/action 토큰, 0.02초 간격의 2초 실험 계약. 첫/마지막 state 시각 차이는 1.98초.
  • 관련 단위 테스트 14개 통과. 단위 테스트 결과와 실제 후보의 물리 실패를 구분.

허용 관통은 발·비발·자체 충돌 각각 2 mm 이내입니다. 두 후보 모두 접촉 발 수는 최소 2개를 만족하고, 자세 quaternion과 관절 한계도 통과했습니다. 그러나 지면을 수 cm 관통하여 초기 상태가 유효하지 않습니다. 이때 접촉 개수가 많다는 것은 안정적인 지지를 의미하지 않습니다.

E는 유한하며 활성 좌표는 [0.05,0.95] 범위, 비활성 좌표 0·11·12는 0.5입니다. 이 범위 검사는 E와 S₀의 물리적 정합성을 보장하지 않습니다. 실제 실패는 두 값을 함께 적용한 geometry 검사에서 발견됐습니다.

MJX 결과를 0 reward나 낙상으로 기록하지 않음MJX 초기 forward 접촉은 확인했지만 시간 stepping은 수행하지 않았습니다. 실제 reward=null, valid time=0이며, 이는 0초 만에 낙상했다는 의미가 아닙니다.

해석과 다음 단계

이번에 좁혀진 병목: 생성 E와 초기 자세 S₀의 물리적 정합성Reward 신호가 E에 도달하지 않는 배선 문제는 이번 후보에서 관측되지 않았습니다. Guidance가 없는 baseline부터 관통하므로 현재 실패를 reward guidance만의 문제로 설명할 수 없습니다.
  • 이번은 seed 0의 한 쌍 결과입니다. 전체 생성 분포의 유효율이나 원인을 확정하지 않습니다.
  • 낮은 denoising loss만으로 geometry 제약이 충족되지는 않음을 실제 후보에서 확인했습니다. 학습 부족·생성 오차·표현 변환 중 원인을 분리해야 합니다.
  • 다음 진단은 학습 데이터의 실제 S₀를 동일한 state 변환·physics audit에 통과시켜 검사기/변환의 정합성을 확인하고, 생성 S₀와 비교하는 것입니다.
  • 그 후 여러 seed의 baseline 유효율을 측정해 국소 실패인지 반복되는 실패인지 확인합니다. 허용 관통을 완화하거나 높이를 보정해 이번 gate를 통과시키지는 않았습니다.
  • 10초 검증 전에 최소 하나의 물리적으로 유효한 생성 시작 상태와 2초 MJX replay 결과가 필요합니다.

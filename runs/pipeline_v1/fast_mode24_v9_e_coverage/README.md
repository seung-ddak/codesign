# v9 형상 범위 확대 검증

**판정: 미학습 형상의 움직임 예측 개선과 Co-Design Gate 모두 미달.**

[실험 보고서·그래프·실제 MJX 영상 32개](report.html)

- 학습: 기존 16개 + 신규 32개 형상, 60,000스텝, 배치 32, Mode 2·4·FiLM. 신규 시험 형상 8개 제외.
- 비교: 동일 사례 516쌍·8 seed·v8 기준 오차 단위, 동일 행동 검사. 반복 형상쌍이므로 516개가 모두 독립 표본은 아니다.
- 결과: 높이/기울기/속도 일치도 개선 +0.028/+0.108/−0.089. 기준은 세 항목 모두 +0.1.
- MJX: 2초 경로 차 18.2cm(기준 15cm), 4초 공동 생성 생존 지그재그 8/16·원형 4/16. 10초 평가는 미실행.
- 자원: CPU 2코어, 평가 GPU 사용 최대 약 2.2GiB, 시스템 RAM 여유 최소 13.3GiB.

원자료와 설정·해시: `evaluation_local/comparison.json`, `conditions.json`, `status.json`. 학습 로그는 `train_local.log`, 학습 체크포인트는 `tt_joint/checkpoint.pt`. 결과 재작성은 `build_report_local.py`. 형상 수와 데이터 양이 함께 늘었으므로 각각의 원인 효과는 분리하지 않았다.

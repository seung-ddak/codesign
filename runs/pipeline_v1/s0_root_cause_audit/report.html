요약

생성 E·S₀ 두 쌍의 물리적 불일치 재확인선택된 정상 실제 상태 9개는 변환·복원을 통과했고, 저장된 Smoke의 발 높이도 재현했습니다. 따라서 이 표본의 수 cm 관통은 변환 경로의 일반적 오류보다는 생성된 형상·초기 자세 조합에서 발생한 것으로 좁혀집니다. 모델 내부의 구체적 원인은 아직 확정하지 않았습니다.

실제 qpos·qvel → TT features → 공유 s0_to_q → MuJoCo 검사에서 9/9 통과했습니다. 발 높이 최대 오차는 기록 정밀도 기준 0.000000 mm, 토큰 최대 오차는 0.00000000입니다. 이 결과는 선택된 표본에 한정됩니다.

무엇이 확인됐고 무엇이 남았는가

  • 정상 실제 데이터는 현재 모델·변환 경로에서도 정상으로 복원됩니다.
  • 저장된 Smoke 관통이 같은 geometry에서 재현되므로, 이번 결과를 단순한 실험 설정 차이로 설명할 근거는 없습니다.
  • 생성 E·몸통 높이·관절각이 함께 물리 조건을 충족하지 못했습니다. E 하나 또는 높이 하나만을 원인으로 확정하지 않습니다.
  • 두 후보의 높이가 동일하게 0.155553 m인 것은 관측 사실입니다. 그 이유가 정규화·clamp·학습·sampling 중 무엇인지 이번 코드는 분리하지 않습니다.
  • 원본 데이터에도 일부 관통이 관측됐습니다. 학습 데이터의 관통 분포와 생성 결과를 더 넓게 비교해야 합니다.
  • 다음 후보 진단: 여러 seed의 무guidance 생성 유효율, E별 높이·관절각 정합성, 생성 높이의 정규화/clamp 위치를 확인합니다.

추가 학습·새 공동 생성·MJX 시간 stepping은 수행하지 않았습니다. 진단 대상은 기본 e000/e001/e002와 기존 seed 0의 생성 두 쌍입니다.

원인

DesignScorer 는 π_θ run 의 designs.json 구조 그룹마다 MJX 슬롯을 한 번 컴파일하고, 새 형상은 같은 구조 키의 슬롯에 넣어 채점합니다. 그래서 π_θ 가 학습한 구조 키만 채점할 수 있습니다.

이 파일럿은 stage2/runs/t5_norail_x3_1000it 를 썼습니다. 이 run 은 --max-groups 4 라 구조 키가 ['00000', '00001'] 두 개뿐입니다. TT prior 가 첫 배치에서 링크 다리(bit 2)가 켜진 01000 형상을 만들자 목록에 없어 예외가 났습니다.

파이프라인 테스트가 통과한 이유: 테스트용 fake_t5 는 T5_try1 의 designs.json(16 구조 전부)을 붙여 둬서 이 경로가 드러나지 않았습니다.

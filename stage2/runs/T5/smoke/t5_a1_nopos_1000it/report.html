T5 π_θ 학습 발자취

형상 E 를 입력으로 받아 128 개 형상을 한 정책으로 걷게 하는 π_θ 를 학습했습니다. 이 페이지는 9월 25일 첫 스크리닝부터 오늘 평가·영상까지의 과정을 순서대로 정리합니다.

최종 run runs/t5_a1_nopos_1000it체크포인트 0000245760002026-09-27 기준

지금 상태

이전 run 보다 확실히 나아졌지만 아직 완성은 아닙니다. 평가 에피소드의 절반 이상이 20 초를 채우기 전에 몸통이 바닥에 닿아 끝납니다. torques 페널티는 오히려 커졌습니다.

코드 흐름

  1. TT 형상 bank 에서 choice 8 비트 + seed 를 뽑아 MJCF 로봇을 조립
  2. 구조가 같은 형상끼리 묶어 MJX 에서 vmap 으로 동시에 시뮬레이션
  3. legged_gym 보상 10 항으로 PPO 가 π_θ 를 학습
  4. 체크포인트를 같은 환경에서 평가하고 영상으로 확인

진행 과정

실패한 시도도 전부 적었습니다. 각 단계의 결과가 다음 결정의 근거가 됐습니다.

    학습 곡선: 음수 보상을 자를 때와 자르지 않을 때

    두 run 은 only_positive_rewards 하나만 다릅니다. 나머지 설정(action_scale 0.25, adaptive KL, 128 형상, 1024 env)은 같습니다.

    only_positive 켬 (t5_a1_1000it, 13.6M 에서 중단)only_positive 끔 (t5_a1_nopos_1000it)

    켰을 때: 거의 모든 step 의 보상이 0 으로 잘려 학습 신호가 사라졌습니다. 정책 표준편차가 1.04 에서 1.92 로 커지면서 행동이 점점 무작위가 됐고, 에피소드 길이는 55 step 근처에서 멈췄습니다.

    껐을 때: 1.5e7 step 부근부터 버티는 시간이 급격히 늘었습니다. 표준편차는 0.95 에서 0.50 으로 줄어 정책이 수렴하는 방향이었습니다. 2e7 step 이후로는 보상과 길이 모두 거의 평평합니다.

    평가: 보상 항목 분해

    학습과 같은 환경(관측 노이즈, 밀기, 마찰 DR, 무작위 명령)에서 128 형상 × 4 에피소드를 결정적 정책으로 돌린 평균입니다. 값은 에피소드 합이며, 양수는 보상 항, 음수는 페널티 항입니다.

    형상별 결과: 상위 형상과 하위 형상

    형상은 TT design space 의 choice 8 비트와 seed로 정해집니다. 이번 학습은 앞 4 비트가 0000 인 16 개 choice 만 썼고, choice 마다 seed 8 개를 뽑아 128 형상이 됐습니다. seed 는 다리 길이, 몸통 길이, 다리 벌림 각도, 팔·배터리 위치 같은 연속값 13 개를 정합니다.

    bit 4뒤-오른쪽 다리가 링크(rod) 구조 다리로 바뀜 (+0.3 kg)
    bit 5팔(arx5)이 고정 마운트 대신 레일 위에 올라감 (+1.2 kg)
    bit 6앞다리 두 개의 무릎 굽힘 방향 반전
    bit 7뒷다리 두 개의 무릎 굽힘 방향 반전

    상위 / 하위 형상의 뜻: 평가 return 순위에서 위쪽이냐 아래쪽이냐를 말한 것입니다. 형상 자체의 좋고 나쁨이 아니라 지금 π_θ 가 그 몸을 얼마나 잘 다루는가입니다.

    가장 뚜렷한 차이는 무릎 방향(bit 6, 7)입니다. 뒷무릎만 반전(xx01)이 평균 생존율 0.69, return 4.0 으로 가장 좋았습니다. 앞무릎만 반전(xx10)은 생존율 0.41, return 0.8 로 가장 나빴고 collision 페널티가 두 배였습니다. 팔 레일(bit 5)은 무게가 늘어 return 이 3.4 에서 2.2 로 떨어졌고, 링크 다리(bit 4)는 차이가 거의 없었습니다.

    같은 choice 안에서도 seed 에 따라 return 이 1.2 에서 10.6 까지 벌어집니다(최상위 choice 00001001 기준). 비트만으로 결과가 정해지지는 않습니다.

    평가 영상

    평가 순위 1 위, 64 위(중간), 128 위(최하위) 형상입니다. 영상은 평가와 별도로 형상 하나를 에피소드 하나만 돌려 찍었습니다. 한 번의 에피소드라서 평가 평균과 차이가 크고, 이 환경에는 마찰 DR 이 빠져 있습니다. 세 영상 모두 1000 step 을 채우기 전에 쓰러졌습니다.

    남은 문제와 다음 후보

    • 앞무릎 반전(xx10) 계열이 추종을 거의 못 함. 원인 진단 후보

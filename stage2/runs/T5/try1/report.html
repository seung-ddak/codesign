    선속도 추종은 최대치 대비 % 로 그렸습니다. 점선 19 % 는 무작위 명령에서 서 있기만 해도 받는 몫입니다.

    평가: 명령별 결과

    모든 형상이 같은 대칭 고정 명령 7 개(전진·후진·왼쪽·오른쪽 0.5 m/s, 빠른 전진 1.0 m/s, 좌·우회전 0.5 rad/s)를 한 번씩, 20 초 동안 유지해서 받습니다. 학습 명령은 원본 무작위 범위 그대로입니다. 평가에는 무작위화(관측 노이즈, 밀기, 마찰)를 끕니다(D52, legged_gym play.py 와 같음). 이동은 명령 방향으로 실제 간 거리, 회전은 명령 방향으로 실제 돈 각도의 비율입니다.

    평가 영상

    무작위 명령 영상은 run 끼리 비교하려고 명령 seed 를 1 로 고정했습니다(학습과 같은 방식으로 뽑은 명령, 10 초마다 바뀜). 고정 명령 영상은 평가 명령 7 개를 5 초씩 이어 붙였습니다(전진 → 후진 → 왼쪽 → 오른쪽 → 빠른 전진 → 좌회전 → 우회전). 앞다리 주황, 뒷다리 회색, 곧은 초록 화살표 = 이동 명령, 휘어진 초록 화살표 = 회전 명령(반시계 = 왼쪽).
